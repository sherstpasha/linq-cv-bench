==================================================
1. HOSTS AND ENVIRONMENTS
==================================================

There are 3 Python environments in the final workflow.

1. TPU / H1 environment
   Path: /home/smallpc_user/linq_venv311
   Purpose:
   - self-build TPU classification
   - self-build TPU segmentation
   - vendor TPU classification
   - vendor TPU detection
   - MLPerf runs for TPU
   Notes:
   - this environment must have libtpu / tpu-dkms / pytpu / tpu_framework / mlperf
   - do not mix it with CUDA-only packages

2. ONNX CPU/CUDA environment
   Path: /home/smallpc_user/linq_cuda_venv
   Purpose:
   - ONNX CPU and CUDA baselines for classification
   - ONNX CPU and CUDA baselines for segmentation
   - ONNX CPU and CUDA baselines for detection

3. Strict tiny_yolo3 export environment
   Path: /home/smallpc_user/linq_tf_export_venv
   Purpose:
   - export the strict tiny_yolo3 ONNX model from pjreddie cfg/weights

Important runtime note for ONNX CPU/CUDA runs:
- always unset these variables before ONNX Runtime commands:
  unset LD_LIBRARY_PATH
  unset CUDA_HOME
  unset CUDA_PATH

Important host note:
- TPU sections below require a host with real TPU devices
- if /dev/tpu0 is missing, skip TPU sections and run only ONNX CPU/CUDA sections

3. TPU RUNS
==================================================

Final TPU plan:
- classification: self-build ResNet-50, presets O1 and O5
- segmentation: self-build FCN-ResNet50, preset O1
- detection: vendor tiny_yolo3 TPU program
- vendor comparison: resnet50_mlperf

--------------------------------------------------
3.1 Classification TPU self-build (O1)
--------------------------------------------------

source ~/linq_venv311/bin/activate && python $REPO/scr/classification/run_resnet50.py \
  --python $TPU_PY \
  --mlperf-binary $MLPERF \
  --model-path $REPO/models/classification/resnet50_${SUFFIX}.onnx \
  --calibration-dir $REPO/data/calibration/imagenet \
  --evaluation-dir $REPO/data/evaluation/imagenet \
  --artifacts-dir $REPO/artifacts/classification_${SUFFIX} \
  --experiments-dir $REPO/experiments/classification_${SUFFIX} \
  --reexport-model \
  --accuracy-samples 5000
