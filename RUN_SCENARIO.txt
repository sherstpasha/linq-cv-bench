==================================================
1. HOSTS AND ENVIRONMENTS
==================================================

There are 3 separate Python environments in the final workflow.

1. TPU/H1 environment
   Path: /home/smallpc_user/linq_venv311
   Purpose:
   - self-build TPU classification
   - self-build TPU segmentation
   - vendor TPU detection
   - MLPerf runs for TPU
   Notes:
   - this environment must have pytpu / tpu_framework / tpu_compiler / mlperf
   - do not install ultralytics or random CUDA/GPU packages here

2. ONNX CPU/CUDA environment
   Path: /home/smallpc_user/linq_cuda_venv
   Purpose:
   - ONNX CPU and CUDA baselines for classification
   - ONNX CPU and CUDA baselines for segmentation
   - ONNX CPU and CUDA baselines for detection
   One-time setup:

   python3 -m venv ~/linq_cuda_venv
   source ~/linq_cuda_venv/bin/activate
   python -m pip install --upgrade pip setuptools wheel
   python -m pip install \
     "numpy==1.26.4" \
     "onnx~=1.16.0" \
     "onnxruntime-gpu==1.24.2" \
     "torch==2.10.0" \
     "torchvision==0.25.0" \
     "pycocotools==2.0.11" \
     "opencv-python" \
     "Pillow"

   GPU sanity check:

   source ~/linq_cuda_venv/bin/activate
   unset LD_LIBRARY_PATH
   unset CUDA_HOME
   unset CUDA_PATH
   python - <<'PY'
   import torch
   import onnxruntime as ort
   print("torch:", torch.__version__)
   print("torch cuda:", torch.cuda.is_available())
   print("ort:", ort.__version__)
   print("providers:", ort.get_available_providers())
   PY

3. Strict tiny_yolo3 export environment
   Path: /home/smallpc_user/linq_tf_export_venv
   Purpose:
   - export strict tiny_yolo3 from pjreddie cfg/weights to ONNX
   One-time setup:

   python3 -m venv ~/linq_tf_export_venv
   source ~/linq_tf_export_venv/bin/activate
   python -m pip install --upgrade pip setuptools wheel
   python -m pip install \
     "numpy==1.26.4" \
     "tensorflow==2.14.1" \
     "tf2onnx~=1.16.1" \
     "onnx~=1.16.0" \
     "h5py"

Important runtime note for CUDA runs:
- for ONNX CPU/CUDA commands use:
  unset LD_LIBRARY_PATH
  unset CUDA_HOME
  unset CUDA_PATH
- this avoids mixing system CUDA libs with pip CUDA libs

Important host note:
- TPU sections below require a host with a real TPU device
- if the current host has no TPU processor, skip TPU sections and run only ONNX CPU/CUDA sections
